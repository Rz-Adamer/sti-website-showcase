# STI Website

Sitio web corporativo desarrollado para un servicio técnico especializado en reparación y mantenimiento de impresoras.

> **Importante:** Este repositorio es una presentación del proyecto. El código fuente se mantiene privado.

---

## Sitio web

**Demo:** https://www.printersolutionsxpress.com/ 

---

## Descripción

El objetivo del proyecto fue desarrollar un sitio web profesional para mostrar los servicios de la empresa, facilitar el contacto con los clientes y mejorar su presencia en internet.

El sitio fue desarrollado completamente desde cero utilizando PHP nativo, HTML, CSS y JavaScript.

---

## Tecnologías utilizadas

### Backend

- PHP 8
- MySQL

### Frontend

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome

---

## Características

- Diseño responsive
- Optimización SEO básica
- Formularios de contacto
- Integración con WhatsApp
- Gestión de contenido mediante PHP
- Organización modular del proyecto
- Optimización para dispositivos móviles
- Integración con Google Maps
- Certificado SSL
- Dominio personalizado

---

## Despliegue

El proyecto se encuentra desplegado en producción utilizando:

- Hosting: Hostinger
- Base de datos: MySQL
- Dominio personalizado
- SSL habilitado
- Cloudflare para gestión DNS y seguridad
